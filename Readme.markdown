# \# EXO VET FIND 🐾

# 

# \*\*특수 동물 전문 동물병원 정보 검색 및 공유 플랫폼\*\*

# 

# \## 1. 프로젝트 소개

# 

# EXO VET FIND는 특수 동물을 키우는 보호자들이 자신의 반려동물에게 적합한 동물병원을 보다 쉽게 찾을 수 있도록 돕는 웹 서비스입니다.

# 

# 일반적인 반려견·반려묘 중심의 동물병원 정보에서 벗어나, 새, 햄스터, 고슴도치, 토끼, 파충류 등 다양한 특수 동물의 진료가 가능한 동물병원 정보를 한곳에서 확인할 수 있도록 하는 것을 목표로 합니다.

# 

# 지역, 진료 가능 동물, 진료 항목 등을 기준으로 병원을 검색하고, 병원별 상세 정보와 실제 방문 경험을 공유할 수 있는 서비스를 개발하고자 합니다.

# 

# \## 2. 프로젝트 목표

# 

# \- 특수 동물 진료가 가능한 동물병원 정보를 통합적으로 제공

# \- 동물 종류 및 지역에 따른 병원 검색 기능 제공

# \- 병원별 진료 가능 동물과 진료 항목을 구체적으로 안내

# \- 사용자들이 병원 정보를 직접 등록하고 공유할 수 있는 환경 구축

# \- 실제 방문 후기와 이용자 경험을 통한 정보 공유 활성화

# 

# \## 3. 주요 이용 대상

# 

# \- 특수 동물을 반려동물로 키우는 보호자

# \- 특수 동물 진료가 가능한 동물병원을 찾는 사용자

# \- 병원 정보를 등록하거나 관리하고자 하는 동물병원 관계자

# \- 특수 동물 진료 및 병원 정보를 공유하고자 하는 사용자

# 

# \## 4. 주요 기능 및 개발 계획

# 

# \### 1차 제출 — 기본 병원 정보 조회 서비스

# 

# \- 서비스 소개 및 메인 화면

# \- 특수 동물 병원 목록 조회

# \- 병원별 상세 정보 조회

# \- 동물 종류 및 진료 항목 분류

# \- 초기 병원 데이터 15개 이상 등록

# \- PC 및 모바일 반응형 화면 구현

# 

# \### 2차 제출 — 병원 검색 및 필터링 서비스

# 

# \- 지역별 병원 검색

# \- 동물 종류별 병원 검색

# \- 진료 항목별 병원 검색

# \- 여러 검색 조건을 조합한 복합 검색

# \- 검색 결과 없음 안내

# \- 검색 조건 초기화 기능

# 

# \### 최종 제출 — 사용자 참여형 정보 공유 플랫폼

# 

# \- 회원가입 및 로그인

# \- 사용자 프로필 및 계정 관리

# \- 신규 동물병원 정보 등록

# \- 병원 최초 등록자 및 등록일 표시

# \- 병원 정보 확인 상태 표시

# \- 병원별 댓글 작성 및 조회

# \- 실제 방문 후기 작성 및 조회

# \- 작성한 댓글 및 후기 수정·삭제

# \- 사용자 권한 및 데이터 접근 제어

#

# \## 6. 개발 및 관리 방식

# 

# \- GitHub 저장소를 활용하여 소스 코드를 관리합니다.

# \- GitHub 웹사이트에서 파일을 생성하고 수정하는 방식으로 개발합니다.

# \- 기능 단위로 변경 사항을 커밋하여 개발 이력을 기록합니다.

# \- Supabase를 활용하여 병원 및 사용자 관련 데이터를 관리할 계획입니다.

# \- Vercel을 활용하여 실제 접속 가능한 웹사이트를 배포할 계획입니다.

# \- 각 제출 단계에서 구현된 기능을 직접 테스트하고 결과를 기록합니다.
